Temporary Instructions

- Add your script into a folder in nova-act-local
- Make sure you have a log directory set and turn on video recording
- Run your script and capture the logs

- Open nova-act-local/tools/parse.py and update the input and output dirs
- Run the script
- Copy the contents of your parsed logs folder into src/frontend/src/pages/Flow/example_output
