## Generative AI Labs demo documentation

During the creation of a demo many assets are created. In order to track each of these, the following set of 
documents have been provided to serve as a source of truth for the locations of any assets outside the repo, 
as well as a record of progress towards any required steps or reviews.

They are intended to be included in the repo alongside the demo code in a directory named "governance".

 ### [1. Project details](./1-PROJECT-DETAILS.md)
This contains the overall information about the project, and serves as a quick overview for people without having to dig for it.

### [2. Security checklist](./2-SECURITY-CHECKLIST.md)
This tracks the progress towards required security activities, and collects up links to all needed information for reviews. 
It also captures links to security reviews, as well as providing a record of models and data usage and handling.

### [3. Architecture checklist](./3-ARCHITECTURE-CHECKLIST.md)
This captures all the high level architecture details for the final design, including the architecture diagram and links to reviews.
It should capture any tradeoffs made in the final architecture and what would changes would be needed to "productionise" it.

### [4. Tech alternatives](./4-TECH-ALTERNATIVES.md)
This sits alongside the Architecture checklist. It shows information on the services chosen at a much lower-level than the Architecture checklist,
and also captures information on any other services and solutions that were considered and the reasons why they were not used. 

### [5. Implementation checklist](./5-IMPLEMENTATION-CHECKLIST.md)
This serves as the team norms for coding and development standards. 
A recommended set of guidelines has been provided, but the team can expand or adjust these as needed.
Anyone working on the code in this repo should be able to understand the processes and expectations based on this document.

### [6. Final demo checklist](./6-DEMO-CHECKLIST.md)
This tracks progress towards "ready to onboard" to the demo portal.
